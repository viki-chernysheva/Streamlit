# 🌏 Travel Planner — учебный проект на Streamlit

Интерактивное веб-приложение, которое помогает подобрать путешествие по стране, бюджету и типу отдыха. Проект создан для знакомства с фреймворком **Streamlit** и основами веб-разработки на Python в среде **PyCharm**.

## 📋 Что делает приложение

Пользователь выбирает:
1. **Страну** — Франция, Италия или Россия
2. **Бюджет** — от 10 000 до 500 000 ₽ (слайдер)
3. **Тип отдыха** — Море, История или Еда

После нажатия кнопки **«Предложить путешествие»** приложение:
- Показывает выбранную страну на карте (`st.map`)
- Определяет уровень бюджета: **Эконом** / **Стандарт** / **Люкс**
- Выдаёт рекомендацию под выбранный тип отдыха
- Предлагает ссылки на подбор отеля (Островок) и маршрута (Авиасейлс)

Фон приложения — изображение `fly.png`, а сама форма оформлена в виде карточки с тенью.

## 🚀 Как запустить проект в PyCharm

### 1. Клонирование репозитория

**Через PyCharm:**
1. Откройте PyCharm → **File → Project from Version Control**
2. Вставьте ссылку: `https://github.com/viki-chernysheva/Streamlit.git`
3. Нажмите **Clone**

**Или через GitHub:**
Скачать как Zip и разархивировать.
Затем в PyCharm: **File → Open** → выберите папку проекта.

### 2. Установка библиотек

1. Откройте файл `main.py` в PyCharm.
2. Подчёркнутые красным импорты (`streamlit`, `pandas`) означают, что библиотеки не установлены.
3. Наведите курсор на подчёркнутый импорт → нажмите **Install package** (или используйте подсказку PyCharm).
4. Либо установите вручную через терминал PyCharm (**View → Tool Windows → Terminal**):
   ```bash
   pip install streamlit pandas
   ```

> 💡 **Важно:** убедитесь, что в PyCharm выбран правильный интерпретатор Python. Проверить можно в **File → Settings → Project → Python Interpreter**.

### 3. Запуск приложения

Streamlit нельзя запустить обычной кнопкой ▶️ Run — приложение нужно запускать через команду `streamlit run`.

**Способ 1 — через терминал PyCharm:**
1. Откройте **View → Tool Windows → Terminal**
2. Введите:
   ```bash
   streamlit run main.py
   ```
3. В браузере автоматически откроется приложение по адресу `http://localhost:8501`

**Способ 2 — настроить Run Configuration (удобно для повторных запусков):**
1. **Run → Edit Configurations → + → Python**
2. **Script path:** выберите `main.py`
3. **Parameters:** оставьте пустым, но в поле **Interpreter** укажите свой Python
4. **Важно:** в поле `Parameters` ничего не пишем, а вместо этого:
   - В **Run → Edit Configurations → + → Python** выберите тип **Module name**
   - В поле **Module name** введите: `streamlit`
   - В поле **Parameters** введите: `run main.py`
5. Нажмите **OK** — теперь приложение запускается кнопкой ▶️.

### 4. Остановка приложения

В терминале нажмите **Ctrl + C**, либо закройте вкладку Run в PyCharm.

## 🧠 Что изучаем в проекте

- **Основы Streamlit:** `st.title`, `st.selectbox`, `st.slider`, `st.button`, `st.info`, `st.success`
- **Работа с данными:** библиотека `pandas` и `pd.DataFrame`
- **Отображение карт:** `st.map()` с координатами городов
- **Кастомный CSS:** вставка стилей через `st.html()` и кодирование изображения в base64
- **Интерактивная вёрстка:** `st.container`, `st.columns`, `st.link_button`
- **Условия и логика:** `if / elif / else` для подбора рекомендаций

### ❓ Если что-то не работает

| Проблема | Решение |
|---|---|
| `ModuleNotFoundError: No module named 'streamlit'` | Установите библиотеку: `pip install streamlit` в терминале PyCharm |
| `streamlit: command not found` | Используйте `python -m streamlit run main.py` |
| Фон не отображается | Проверьте, что `fly.png` лежит в одной папке с `main.py` |
| Порт 8501 занят | Запустите с другим портом: `streamlit run main.py --server.port 8502` |
